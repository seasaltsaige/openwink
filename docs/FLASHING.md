# Flashing the Module

See [openwink-mcu-platformio](../openwink-mcu-platformio/README.md) to build the firmware with ESP-IDF and PlatformIO.

For production modules, use the **ESP32-S3 N4** environment, `esp32-s3-devkitc-1-n4`.

Initial flashing and recovery instructions are still being written. Initial flashing uses the combined image generated by the build. OTA updates require the signed `update-<version>.bin` file.

If your module already runs OpenWink, you can [update it through the app](./GETTING_STARTED.md#check-for-updates) without removing it from the car.
